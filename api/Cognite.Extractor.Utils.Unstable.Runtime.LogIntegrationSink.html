Class LogIntegrationSink

An extractor integration sink that simply logs the incoming events.

Useful for providing the extractor with a sink, even when it's running without a configured cognite client.

SetActionDispatcher(Func<IReadOnlyList<IntegrationAction>, Task>)

Register the callback to invoke whenever a check-in or startup response contains one or more actions pending execution by the extractor.

The dispatcher is expected to return promptly -- it should hand off actual execution (e.g. to one Run(Action) per action) rather than running actions to completion itself, since it is awaited as part of the regular check-in cycle.
