Class BetaStateSetsExtensions

Extension methods for creating and managing state sets through the beta CDM state set resource. State sets are currently only available through this beta API. These are thin wrappers around Cognite.Extensions.DataModels.CogniteExtractorExtensions.BetaResourceExtensions.
